# arabic-rtl

إضافة لـ Claude Code تعرض الرسائل العربية في المحادثة من اليمين لليسار:

- كل سطر عربي يبدأ من اليمين، وإذا طال يكمّل في السطر اللي تحته من اليمين بعد.
- الكلمات الإنجليزية والكود داخل السطر تبقى قطعة وحدة من اليسار لليمين، وما تلخبط ترتيب العربي.
- الأسطر الإنجليزية بالكامل، وبلوكات الكود، والجداول تبقى مثل ما هي.

## التثبيت

الأسهل من تطبيق Claude على سطح المكتب: افتح تبويب **Code**، اضغط **+** جنب خانة الكتابة،
بعدين **Plugins**، بعدين **Add marketplace** واكتب `eissa1819/arabic-rtl`، بعدين **Add plugin**.

أو من جلسة Claude Code في الطرفية (Terminal):

```
/plugin install arabic-rtl --marketplace eissa1819/arabic-rtl
```

اكتب `y` عشان تضيف المصدر، بعدين اختر نطاق التثبيت (user).

أو من سطر الأوامر:

```bash
claude plugin install arabic-rtl --marketplace eissa1819/arabic-rtl
```
